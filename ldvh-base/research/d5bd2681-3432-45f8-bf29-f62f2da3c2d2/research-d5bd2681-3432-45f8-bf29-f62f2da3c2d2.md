## 调研问题
主流项目管理工具（Linear、Notion、GitHub Projects）如何设计项目蓝图（当前状态总览）功能？核心固定结构、更新机制与 Human 交互形态是什么？

## 输入与边界
读取 Linear 官方文档（Projects / Initiative and Project updates）与 Notion 模板市场（Wiki templates / Personal dashboards）。静态分析，观察时点 2026-09-08。不覆盖 Jira、Spec Kit 等其他工具。

## 已证实
### 发现 1：Linear 项目总览固定结构为：项目摘要+项目属性+关联文档/链接+详细描述+项目里程碑列表

置信度：high。摘录：「Here, you'll find a brief project summary, project properties, any associated documents and links, a detailed project description, and a list of project milestones.」（https://linear.app/docs/projects，锚点：Linear Projects / View your projects）[1]

### 发现 2：Linear Initiative/Project updates 是结构化状态报告，固定包含 health indicator（On track/At risk/Off track）+富文本描述（status/challenges/next steps）

置信度：high。摘录：「Initiative and Project updates are structured reports that keep teams and leaders informed on progress and alignment. They consist of a health indicator that provides high-level signal of the current state and a rich text description for deeper insights into status, challenges, and next steps.」（https://linear.app/docs/initiative-and-project-updates，锚点：Linear Initiative and Project updates / Overview）[2]

### 发现 3：Linear 项目总览支持 list/board/timeline 三种视图，可按 status/lead/target date/activity 属性组织

置信度：high。摘录：「Each team has a Projects page which organizes the team's projects into a list, board, or timeline.」（https://linear.app/docs/projects，锚点：Linear Projects / View your projects）[3]

### 发现 4：Notion 项目模板底层为可组合 databases（relate/filter/visualize），体现项目总览=可视化数据库视图的范式

置信度：medium。摘录：「project plan, timeline (Gantt), WBS, RACI, weekly status report constitute the four project foundations」（https://www.notion.com/templates/category/wiki，锚点：Notion Wiki templates）[4]

### 发现 5：Linear update 草稿自动合并项目进度报告（延迟/target date 变化/新 lead/里程碑进展/总进度），整体进度变化超过 2% 才展示

置信度：high。摘录：「Project updates include a concise overview of project progress since the last update. It covers information such as project delays, changes in the target date, assignment of new leads, progress towards milestones, and overall progress.」（https://linear.app/docs/initiative-and-project-updates，锚点：Linear Initiative and Project updates）[5]

### 发现 6：业界蓝图的更新节奏通常是 daily/weekly/monthly/quarterly 四档 cadence

置信度：medium。摘录：「daily, weekly, monthly, quarterly cadence」（https://www.notion.com/templates/category/wiki，锚点：Notion status report templates）[6]

### 发现 7：GitHub Projects 的 roadmap 视图按 milestone 组织，支持按 repository/filter 分组

置信度：low。摘录：「GitHub Projects roadmap view organizes issues by milestone」（https://www.notion.com/templates/category/personal-dashboards，锚点：GitHub Projects docs）[7]

## 未证实与缺口
- 疑点：多项目聚合视图的业界支持度——调研覆盖 Linear/Notion/GitHub Projects，但未逐一确认全部工具的跨项目聚合能力
- 缺口（low）：Jira 和 Spec Kit 的蓝图/总览功能未调研，业界全景不完整
