### F2 消息级反馈改为对称提交：toggle 更名 retract、openDialog 增 rating 参数、MessageFeedbackToggleResult 移出客户端导出

行为变更：原「Like 立即记录 + 致谢 toast、Dislike 开对话框收集理由」改为「任一未记录评级都先开共享反馈对话框、提交后才记录；点击已记录评级直接 retract（在控制器序列化队列内复核已提交项，并发变更时 no-op，不会把过期 UI 意图变成裸评级写入），不开对话框」。正面反馈从此同样可携带 category 与 note；提交失败从对话框内联文本改为 6 秒警告 toast（IconWarningOutline16），对话框保持草稿不关，新增 dismissFailure 注入动词。API 面：`MessageFeedbackController.toggle` → `retract`（返回 `MessageFeedbackActionResult`，不再携带 rating）；`MessageFeedbackToggleResult` 类型从 `src/client/index.ts` 导出移除；注入面 `openDialog(messageId)` → `openDialog(messageId, rating)`、移除 `acknowledge`（转私有）；`FeedbackDialogTarget` 的 message 分支新增 `rating` 字段。Host 侧 `packages/feedback/message-feedback/src/types.ts` 仅注释措辞变化（category 语义从「负面判断」放宽为「判断」），协议与 Remote 无变化。locales：`category.service-stability` 文案改为「稳定性和速度/Stability and speed」。发布级 e2e（feedback-release）已把 Like 也改为经真实对话框提交，并核对上传面板与 telemetry 释放。

家族价值判断：这是本差量中唯一可能触碰家族代码的 API 改名，但影响面极窄——只有深导入 ui-message-feedback 客户端类型（`./src/*` 路径）或复用其 assistant-actions/overlay 注入面的项目受影响；LDVH 与绝大多数家族项目不在此列。
