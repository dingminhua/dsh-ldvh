# Git Gate 子进程无会话身份致校验接入即失效

## 现象
Git Gate runner 运行在 git hook 子进程中，无 sessionPersistence/agent，接入依赖会话路由的取值来源校验后恒返回 unverifiable，成为永不触发的分支。

## 入账依据
根因可归因：checkSignatureAgainstRoute 硬依赖 caller 会话身份，而 hook 模板与 runner 之间既无 session id 传参也无按 id 读会话日志的链路，故校验函数在其执行环境中不可达其数据源。修这条（hook 传 session id + runner 按 id 读会话日志，或无身份时显式判失败而非走 unverifiable）能让 09 §5.1 的取值来源校验在终闸真正可执行，并阻止「以为已接线、实为死分支」的自欺形态再次出现。
