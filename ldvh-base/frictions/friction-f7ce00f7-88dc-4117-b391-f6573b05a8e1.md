# Goal 回合注入被宿主改写致续做指令落空

## 现象
宿主在 goal 回合向会话注入的是管辖判定块与时间采样，用户在该轮请求的「继续完成修复线」未出现在会话可见文本中，执行侧只能靠推测还原该指令。

## 入账依据
turn 20 的 user 行仅含管辖判定块；assistant 回合开头即以「The user says "那你继续完成修复线"」起述，说明该指令未以可见文本送达而被逆向推断。可归因于宿主 goal 回合的注入路径；修复完成后推进/提交类工作不再需要每轮重建意图，故修了会更好。
