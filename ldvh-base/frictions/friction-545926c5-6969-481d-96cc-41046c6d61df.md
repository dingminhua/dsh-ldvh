# 远程项目列表陈旧挂载致项目数感知不一致

## 现象
LDVH 远程 Web 页面因项目列表只在打开时读取一次不轮询、切换器折叠态仅显示当前单个项目，用户将本地2/远程1的差异反复误判为数据丢失，需逐个接口与进程核验才确认是同一份文件同一进程。

## 入账依据
可归因性：助手经隧道与直连实测各项目端点均返回 2，且确认同一文件同一进程（PID 12908 同宿主），最终把差异锁定到客户端「只在打开时读一次、不自动更新」的陈旧挂载，以及「收起时只显示当前选中的那一个」的折叠态设计——成因明确归属 LDVH Web 呈现层。修了会更好：若能令项目列表随新登记刷新（轮询或经 reloadKey 自愈），并在折叠态与展开态之间对齐计数呈现，可消除用户反复核查数据源、误以为数据丢失的排查成本。
