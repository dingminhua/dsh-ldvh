# 测试全绿信号无法担保路径被走过

## 现象
全套 1283 条测试全绿、且经三次独立复核通过，但 lifecycle.js 的落地路径上仍有一行每次运行都抛 ReferenceError 的代码。

## 入账依据
可归因性：测试是围绕**被调用方**（runIdleCheckpoint、landDiscoveryVerdict）组织的，而**调用方**（lifecycle.js 的 onSessionCheckpoint 回调）从未被驱动——故「全绿」在结构上就排除了接线层缺陷这一整类。修了会更好的预期：补上调用方覆盖后，D8 会在第一次运行就被抓住，且此后每一次改动的「全绿」都能对接线本身作出保证，而不只是对被调用的函数。

补充观察（2026-10-11T05:20:17.614Z）：本次材料中两次出现「护栏验证输出 0 失败」而该结果毫无信息量：其一，为 `|| previous.truncated` 保护所配的测试因所守分支**不可达**而恒为通过，护栏形同虚设却从未暴露；其二，`python3 -c` 里的转义未匹配，被测代码**根本没有改动**，于是「0 失败」被一度读成「测试太松」——若据此改动断言或放宽判据，护栏就会在无人察觉的情况下失效。两者与既有账目 545cca82「测试全绿信号无法担保路径被走过」是同一阻碍：机械信号不成立，只在被测路径确实被走过时才成立；而本项目所依赖的「故意引入回归→护栏须失败」这一验证动作，其自身「变异确实落地」这一步没有任何机械保障，故阴性结果与真实有效性在外观上不可区分。

补充观察（2026-10-11T08:02:30.042Z）：本次材料（主控派两路独立复核审核其工单优化观点，复核 B 对抗性重断）中，复核 B 明确指出 59b4899d 的 D8 缺陷「躲过 3 复核/1283 测试」而落地链路 D2 全程未接通，根因是测试从未真正驱动调用方——这正是「测试/复核全绿却无法担保关键路径被真正走过」的又一次实例，与既有观察账目 545cca82「测试全绿信号无法担保路径被走过」表述同一，故判 same-obstacle。我作为空闲辅助执行体只作判断不作决定，不评影响等级。另如实声明：材料在 turn 7 assistant 尾部被截断（止于「你先说说：这个汇总里，有没有哪一条跟你的实际体感和判」），未见主控最终收尾与用户后续回应；判断仅依据所见窗口内的内容完成。

补充观察（2026-10-11T23:04:02.820Z）：材料报告测试全绿（1390/1390）与重启后新供给形态（spawn+有界材料）实跑 0 次并存，明确称需要闲置触发后才能验证链条收尾——这正是既有账目 545cca82「测试全绿信号无法担保路径被走过」所述的现象：绿色信号并不等于部署路径被真实走过。二者为同一阻碍，故判 same-obstacle 命中该账目。

## 处置
解药为 WorkCase `59b4899d-7e15-4194-84d1-98d209ae1aa3`（闲时摩擦发现接通子代理派生，outcome=partial）：其执行期共修 9 项缺陷（D1/D2/D3/D5/D7/D8＋复核发现①–⑤，提交链含 `7701080` 接通闭集落地与 `b7479eb` 修 D8）。本账所指现象的针对性解药有三件：①D8 修复——lifecycle.js 落地路径改经 `ctx.get("sessionPersistence")` 取服务，消除必抛 ReferenceError；②调用方接线护栏——friction-landing.test.mjs 以调用方源码形态断言锁住接线缺陷类（裸 `await runIdleCheckpoint` 丢弃返回值、`landDiscoveryVerdict` 未调用、落地失败未按 §8.3 入队、verdict 取值层级错、水位先于落地推进），另加 lifecycle-undeclared.test.mjs 针对未声明标识符——「调用方从未被驱动」这一结构性缺口由静态形态断言补上；③顺序纪律——水位仅在落地成功后推进（复核发现①）。

核验（2026-10-15，A 批销账）：①插件套件 1452/1452 全绿（入账时基线 1283）；②上述接线护栏逐条在套件内在位；③动态证据——修复后机制在真宿主多次全链路实跑并留实物（c2433ad5、f7256b8c、7a64bbe2、ee8165d4、c9c091cf 等由机制写入并经 be47247 等提交），landed 路径被真实走过且留痕——与入账时「路径坏而全绿」的情形相反，补充观察所担心的「实跑 0 次」已被其后的多次真实运行取代。

保证边界（如实声明）：接线护栏是调用方源码形态的静态断言，不动态执行 onSessionCheckpoint 回调——「全绿」对调用方的担保由「静态形态断言＋生产链路实物」合成，不主张单测已动态覆盖回调本身；补充观察所记「变异验证自身无机械保障」（以故意引入回归验证护栏时，变异确实落地这一步无机械保障）属方法论缺口，不在本账解药覆盖内，如实登记在案、不因销账而消失。
