# 终闸触发与取值同源于被检查方

## 现象
Git Gate 终闸的 trailer 取值来源校验只存在于被检查方自愿调用的 precheck 入口，比对值由被检查方自己写入，且 `ci.yml:39-44` 自认 `--no-verify` 可跳过该闸。

## 入账依据
可归因于终闸的「是否调用」与「比对取值」两处输入都产自被检查方，链路中不存在独立触发方与权威取值源；若改为由 CI 侧无条件触发并从实际调用现场取权威值，拦截不再依赖被检查方自觉，同类事故的复发面会实质收窄。
