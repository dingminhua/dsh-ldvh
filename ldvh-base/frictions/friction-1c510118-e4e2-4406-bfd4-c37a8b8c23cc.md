# 暂存区残留致提交范围被静默扩大

## 现象
执行受控提交时 Git 暂存区在本轮 `git add` 之前就已含 3 个非本批文件，若主控未自行发现，本次只应提交 4 个载体文件的提交会变成 7 个文件。

## 入账依据
可归因性：暂存区条目跨操作/跨轮次残留，而提交前的机械预检未把「实际待提交文件清单」与「本批声明范围」做逐条比对，故受控提交的范围完整性完全依赖 AI 每次自行核对暂存区这一人工动作。修了会更好的预期：预检或 Git Gate 增加一条机械比对（待提交清单须与声明范围完全相等，不等即拦截），即可把范围完整性从「靠自查」变为「靠机制」，同类污染不必每次依赖执行体偶然注意到。
