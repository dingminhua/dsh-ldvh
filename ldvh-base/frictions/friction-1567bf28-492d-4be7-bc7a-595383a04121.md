# 删除事实对象连带销毁取证痕迹与验证义务

## 现象
删除一张仍背负四轮建前审核取证与待实盘验证事项的草稿工单后，五个真实缺陷的取证痕迹与该修复的端到端验证入口同时消失，只剩对话口述与单元测试支撑

## 入账依据
可归因于删除前置动作缺失：删除前未把多轮审核取得的缺陷取证落成持久载体，也未确认该单是否仍背负待验证义务；修法明确（删除前强制迁移取证痕迹 + 把待验证事项转交新载体），可保住四个真实缺陷的档案并保住该修复的实盘验证入口，属可修复的系统性缺口而非偏好之争
