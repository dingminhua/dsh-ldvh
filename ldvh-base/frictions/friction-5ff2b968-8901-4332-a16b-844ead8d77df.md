# 以外延枚举回答范围问题致担保范围反复小于实际

## 现象
主控为「本载体还有哪些处违反判据」这一范围问题，反复使用枚举式回答——先按审核点名的行逐行修（漏）；改按判据类扫描（仍未穷尽）；建缺口声明时又用节号枚举划定残留分布（「§6.1／§8／§14／§15.2」），而被独立复审两次独立找出的位置（§1、§15.3）正在枚举之外，导致「声明的担保范围 < 实际未对齐范围」这一结构性缺口反复出现，同一载体的同类问题在四轮内被不同的独立审核各发现一批

## 入账依据
现象归因于本次运行本身：主控在同一载体（`specs/21`）上用了四种不同的「范围答案」——点名清单、判据类清单、节号枚举、以及最后的按判据界定（把范围定义在判据上而不定义在列表上）。前三种都是**外延式**（列出有哪些），只要列表不完备，范围就小于事实；第四种是**内涵式**（按判据界定，声明「一切满足判据的单元均属缺口本体，不因未逐处列举而缩小」），不依赖枚举完备。可复现性：`ab1c713c`（按点名漏改，4 次）、`ba4afa96`（自造判据致过度删除）、`29cda899`（以点名例子清完为据撤除声明）、本条（节号枚举使声明担保范围小于实际）——四者同根，都是**以外延枚举回答范围问题**。修了会更好的预期：若凡是回答「某载体的某类问题覆盖到哪里」一律改用**内涵式界定**（写判据 + 明示「未逐处列举不缩小范围」），则范围不再依赖枚举的完备性，独立审核也不必靠逐轮补枚举来逼近事实；`59c9268` 已把 21 的缺口声明改为该形态，可作为该做法的首个落点。

**与外延枚举的区分判据**：**外延式**——范围 = 已列出的项之并集，未列出者被默认排除，故与事实的差 = 漏列集合（随扫描覆盖面漂移）；**内涵式**——范围 = 满足判据的全体，列举仅供示例且明示非穷尽，故与事实的差恒为 0（只要判据本身正确）。判据本身是否正确由规范原文核对承担（防 `ba4afa96` 式自造判据），不由枚举完备性承担。
