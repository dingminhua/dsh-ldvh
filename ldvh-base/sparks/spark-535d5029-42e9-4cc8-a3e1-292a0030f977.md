# 生命周期验证的 Windows 覆盖

## 当前理解

`governed-project-lifecycle-verification.md`（38 行）记录管辖项目生命周期的当前实现范围与验证。**当前实现范围**：设置页选择实际 Git 根目录；安装事务（登记、初始化 `ldvh-base/` 五类目录、安装或升级 Git common-dir `commit-msg` Hook）；检查（登记、Git 根、common-dir、事实源、Hook 所有权、正文 digest 与 bundle 版本）；卸载 Hook（只删 LDVH 托管 Hook，保留登记与 `ldvh-base/`）；取消管辖（先卸载 Hook，再移除登记，保留 `ldvh-base/`）；DSH Host 启动时自动检查全部登记项目一次，不自动修改。**macOS 已真实验证 10 项**：候选路径必须为实际 Git 根（仓库子目录被拒绝）；首次安装创建 `ldvh-base/{sparks,workcases,adrs,pitfalls,studies}`；首次安装创建登记文件并把首个项目设为默认；Hook 安装于 Git common-dir `hooks/commit-msg`；Hook marker 正文 digest 与 bundle 版本可回读为 `managed`；真实 `git commit` 中非法 message 被阻断；符合最小 Gate 契约的 message 被放行；卸载 Hook 后登记和 `ldvh-base/` 保留；再次安装可修复缺失 Hook 不重复登记；取消管辖移除登记并自动卸载 Hook、同时保留 `ldvh-base/`。**待补**：该文件含「## Windows 范围」章节但内容未完成——Windows 侧的范围与验证尚未补齐，而跨平台是 07 §5 声明的目标（路径须兼容 Windows 盘符、UNC、junction 与 linked worktree）。

（来源：docs/governed-project-lifecycle-verification.md；普查条目 B-11）
