# 过程引导的规则供给：三通道与漏判证据

## 当前理解

**价值链四层**：价值层（对齐 Vibe ＋ 协调 Coding，`00 §1`）→ 动作层（七项业务系统，`00 §2.6`）→ 痕迹层（事实对象，`00 §2.4.2`）→ 供给层（规则文本，AI 据以判断）。Human 2026-11-21 定位纠正：**核心价值是生产过程的引导，不是交付物的引导**。
