# WorkCase card 与详情对齐设计语言

## 摘要

修 WorkCase 列表卡与详情阅读面对齐 Web 设计语言：详情阅读面引用了 7 个 index.css 中不存在的类（ldvh-reading-grid/ldvh-reading-main/ldvh-fact-section/ldvh-fact-fields/ldvh-fact-field-key/ldvh-fact-field-value），外壳与正文段全程无样式；result.satisfied 是布尔却按字符串渲染成裸 true、residual 是数组却按段落渲染；WORKCASE_CRITERIA_SURFACE_CLASS 导出零消费者、WorkCaseProgressTrack 零消费者且带 ldh- 拼写错误类。

## 授权范围

做什么：把 WorkCaseReadingLayout 的外壳与正文段改用设计语言既有承载——外壳对齐其余六类阅读布局的 mb-6 flex flex-col gap-5，正文段改用 ReadingNodeSection（可折叠节点，10 §12 长文须有折叠入口），字段键值改用 DetailInlineField；修正 WorkCaseDetailData 的 result.criteria_checks[].satisfied 为 boolean、result.residual 为 string[]，并在详情按 satisfied 呈现可读文本+可区分形态（10 §12.8 不用颜色/图标单独承载状态），residual 按列表呈现；为 WORKCASE_CRITERIA_SURFACE_CLASS 找到消费者或删除，删除零消费者的 WorkCaseProgressTrack；补设计语言契约测试（断言 WC 详情外壳与正文段使用已定义类，并加一条「引用的 ldvh-* 类必须在 index.css 中定义」的机械守卫）；重建 dist；受控提交。明确不做什么：不改 21 号三态直读的字段闭集与分组语义；不改列表卡的筛选面（lifecycle 五档与 SG 筛选均不动）；不改卡片标签序（类型→优先级→SG→修改次数为 2026-09-13 Human 定案）；不改后端 API 与事实源；不动其余六类阅读布局（它们是本次对齐的样板）；不改 10 号规范文本。

## 计划

- 详情阅读面改用设计语言既有承载：判据——WorkCaseReadingLayout 不再出现 index.css 未定义类；外壳与六类阅读布局同款；正文段用 ReadingNodeSection、字段用 DetailInlineField；tsc 0 错误
- 修正 result 类型与呈现：判据——satisfied 为 boolean、residual 为 string[]；详情按可读文本呈现 satisfied（非裸 true/false），residual 按列表呈现；随类型修正消除消费方 tsc 错误
- 清理零消费者与拼写错误：判据——WORKCASE_CRITERIA_SURFACE_CLASS 有消费者或已删除；WorkCaseProgressTrack 已删除；仓库内无 ldh- 拼写错误类
- 补设计语言契约测试：判据——新增守卫断言 WC 详情引用的 ldvh-* 类均在 index.css 定义、正文段使用 ReadingNodeSection、result 呈现 satisfied 可读文本；测试全绿
