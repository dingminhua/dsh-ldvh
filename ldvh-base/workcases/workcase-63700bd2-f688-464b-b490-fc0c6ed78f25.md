# 详情页 YAML 呈现推广到全类型

## 摘要

把事实对象详情页底部的 YAML 呈现从「按类型白名单」推广到全部类型，学习 spark 的呈现做法。现状核实（2026-09-16）：ObjectDetail 的 YamlDataNode 渲染条件为 `carrier === 'yaml' || objType === 'research' || objType === 'spark'`——workcase/adr/pitfall/friction/norm/goal 详情页均无 YAML 呈现；且 v5 类型全部为 markdown 载体，`carrier === 'yaml'` 分支对 v5 对象已失效。

## 授权范围

做什么：把 ObjectDetail 底部 YamlDataNode 的渲染条件推广到全部事实类型（workcase/adr/pitfall/friction/norm/goal 一并纳入），确认各类型的 YAML 来源（yaml_source 原文优先、reconstructFactYaml 兜底）与 research 的 sortedResearchFrontmatterYaml 特例保持；同步契约测试；重建 Web 产物 dist；受控提交。明确不做什么：不改各类型 ReadingLayout 的字段级呈现；不改后端 API 与关联投影语义；不动 spark/research 现有 YAML 做法（它们是本次学习的样板）；不改 10 号规范文本（若需登记呈现契约另有独立步骤）。

## 计划

- 现状核实各类型 YAML 可得性：判据——列出七类各自的 carrier、yaml_source 可得性与 reconstructFactYaml 适用范围，机械可查
- 渲染条件推广为全类型 + 契约测试更新：判据——ObjectDetail 不再按 objType 白名单判断 YAML 呈现；契约测试断言全类型详情均渲染 YamlDataNode
- 验证三件套与 dist 重建：判据——tsc 0 错误、web 测试全绿、eslint 无新增；dist 重建且 index.html 引用新 hash
- 受控提交：判据——Git Gate passed，提交含代码、测试与说明
