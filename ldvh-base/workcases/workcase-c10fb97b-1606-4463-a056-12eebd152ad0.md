# 闲时辅助适配 startActivation

## 摘要

把闲时辅助的执行体派发从已移除的 subagents.start 迁移到 startActivation，并保住 09 §5.1 的执行体自身署名。

### 现状核实
rc.1 宿主上已实测失败，待处置队列现有 3 条同类记录（bcc60770、86e863aa、5813239c），reason 逐字为「执行体（受管辖隔离子代理）失败：subagents.start is not a function」；idle-checkpoint-runs 末两条 stage=stopped、per_task 为空。暂停面为摩擦发现与经验积累两项，主会话工具、Human Gate、Git Gate 不受影响。

### 契约实测
SubagentActivation 为 { childId, messageId?, result, dispose() }，无 localAgent、无 id。SubagentActivationSpec 为 { provider, label, childId?, request, signal, delivery }，其中必填四项，childId 可选；signal 在 spec 顶层，request 内层保留 parent 与 outputSchema。

其二，署名不必构造最小 header：ctx.agents.get(childId) 可直接取得子 Agent，交 currentRouteValues 使用，与 09 §5.1 同源。

### 边界
