# 两个 Gate 待办组配色区分

## 摘要

### WorkCase 两个 Human Gate 待办组的语义色无法区分
pending_gate1（待批准执行）与 awaiting_gate2（待批准关闭）的徽标同为紫 #8b5cf6，Human 扫读时无法一眼分辨「还没开始」与「已做完待验收」。

### 着色路径不一致
核实中另发现同一卡片内着色走了两条互不相通的路径（徽标经 STATUS_COLORS、卡内提示硬编码 Tailwind 类），致 pending_gate1 的徽标（紫）与自己的卡内提示（琥珀）互相矛盾，而 awaiting_gate2 恰好两处都是紫、反而掩盖了该缺陷。

### 本单处置
本单统一配色来源并为两 Gate 取显著不同的色相，同步 docs/01 §1.10.2 与 docs/10 §4.2，并补契约测试守卫。

## 授权范围

做什么：为两个 Gate 待办组确定显著不同的语义色（pending_gate1 待批准执行 vs awaiting_gate2 待批准关闭，色相距离达标且浅/暗两模式均可区分）；消除双路径着色——ObjectList/WorkCaseReadingLayout/CognitionCenter 共 7 处硬编码 text-amber-*/text-violet-* 改为从唯一来源取色；同步 docs/01 §1.10.2 与 docs/10 §4.2（把「Human 待确认使用紫色系」修订为两个语义相反 Gate 组必须可区分）；补契约测试守卫（两组色值不等 + 色相距离达标 + 卡内提示与徽标同源）；重建 dist；受控提交。明确不做什么：不改 specs/ 下任何规范文本；不改派生分组的派生判据（workcaseLifecycle）；不改 executing/closed 两组已定色；不改筛选 tab 通用配色语言；不改其它类型状态色与其它页面硬编码色；不做第三套主题。
