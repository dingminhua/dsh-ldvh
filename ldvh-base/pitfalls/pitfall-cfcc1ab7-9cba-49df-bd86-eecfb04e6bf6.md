# 子代理中断致结论丢失而落盘产物可复用

## 症状

主控派出的取证／审核子代理在执行中途被中断，其结论从未产生：工作树里的取证产物完整留存，可那份判断只存在于子代理最后一次交付消息中，随中断一并消失。

识别信号：子代理回合结束但话录里只有过程性 assistant 文本、末条为 `(no text)`，没有结论段；而其应当写入的产物文件已在磁盘上且内容完整。

## 触发条件

把「先取证、后出结论」的长任务交给隔离子代理，且结论只通过交付消息回传；子代理在交出结论前被中断（取消、超时、执行体异常等）。本条材料的实际载体是主会话被 cancel（委派深度为 0、无法再派子代理），机制与子代理中断同形。

## 根因

取证与结论是两段：取证的产物落在文件系统里，结论只落在消息流里。中断切断的是消息流，因此产物存活、结论消失。换言之，结论的生命周期被绑定在一条会因中断而丢弃的通道上，而不是绑定在可持久化的载体上。相关缺陷会加剧问题：`plugin/lib/child-session-record.js` 的 `resolveChildFromSessionRecord` 取「最后一条 assistant 文本」当结论——末轮无文本时不报「无结论」，而是把最后一条进度旁白当成结论返回，于是调用方拿到的是 `ok: true` 加一句无关旁白。

## 解决

让结论先落盘再交付：子代理在交出结论之前把结论写进工作树中的文件（或追加进指定载体），交付消息只作为指针与摘要；主控读取时以落盘文件为准，不以消息流为准。中断后可按落盘产物续作，不必重跑取证。

## 规避

派长任务子代理时，任务书写明「结论必须写进 <路径>，交付消息引用该路径」；主控侧收结论时先读文件，文件缺失即判「无结论」，不得用 `resolveChildFromSessionRecord` 的返回值直接当结论（它会把最后一条进度旁白当结论）。例外：短任务、结论一句话即可时，允许只走交付消息，但须接受中断即丢失。

## 验证

已观察（本次复现，载体为主会话）：产物 `/tmp/rep3/artifact.md` 约 4 秒后完整保留三条取证；cancel 之后话录只剩三条 assistant 文本、末条 `(no text)`，结论从未产生。

附加观察：`resolveChildFromSessionRecord` 对该记录返回

```
{"ok": true, "conclusion": "文件已写入。现在我来确认该目录下有哪些 `.js` 文件。"}
```

即把最后一条进度旁白当成结论返回，不因末轮无文本报「无结论」。

### 独立复现验证（2026-11-02）

**复现主体与独立性边界**：主控委派的独立子代理（受管辖隔离子代理，上下文不外泄给本候选），模型与主控相同（deepseek-v4.1-flash），派生于同一会话但上下文隔离；按 01 §12.2 读作「同模型 + 上下文隔离」，不是异模型独立验证。另须披露：因委派深度已为 0，复现的实际载体是主会话而非真子代理，机制同形但主体形态不同。

**复现做法**：让一个会话先写出完整取证到 `/tmp/rep3/artifact.md`，再在交出结论之前取消该会话；随后检查产物文件与话录，并调用 `plugin/lib/child-session-record.js` 的 `resolveChildFromSessionRecord` 读该记录。

**观察结果**：产物约 4 秒后完整保留三条取证；cancel 后话录只剩三条 assistant 文本、末条 `(no text)`，结论从未产生；`resolveChildFromSessionRecord` 返回 `{"ok": true, "conclusion": "文件已写入。现在我来确认该目录下有哪些 `.js` 文件。"}`——把最后一条进度旁白当结论返回。

**判定**：机制复现成功（产物存活、结论随中断丢失），并额外确认一条候选未记的后果：结论解析器会把进度旁白当作结论，且不报「无结论」。

**未覆盖**：真实子代理（而非主会话）被中断的现场；超时与执行体异常两类中断来源；重新派发时复用落盘产物的链路未完整走通。

## 影响与适用范围

适用于主控派生隔离子代理做取证或审核、子代理在交出结论前被中断（超时、取消或执行体异常等）的场合：其已完成的取证若写在工作树或文件里仍可复用，而结论只存在于最后一次交付消息中，随中断一并丢失；不适用于子代理已把结论落盘、或中断发生在任何取证之前的情形。

展开——何时可能踩到：把长任务交给零上下文隔离子代理、且结论只在交付消息中，子代理又在收尾前被中断时；尤其出现在审核子代理被中断了、而它已完成大部分取证的「先取证、后出结论」链路。经验何时可信：工作树里确实留有该子代理的取证产物、且其回合没有已完成结论时，可据此先复用产物再重派；若子代理已把结论写入文件，或中断发生在取证之前，则不适用本条。
