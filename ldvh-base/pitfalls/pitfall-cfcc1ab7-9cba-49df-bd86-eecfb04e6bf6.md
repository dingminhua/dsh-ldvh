# 子代理中断致结论丢失而落盘产物可复用

## 症状

派出的审核子代理在完成大部分取证后被中断，没有交出结论；主控侧只拿到取证痕迹，拿不到审核结论，形成「有产物、无结论」的缺口。

逐字引证（缓冲条目 859b579c-9696-4c9a-9361-3cbb94ca9743 的 evidence，原文复制）：

```
审核子代理被中断了，没有留下结论。
来源：主控会话 turn 114 assistant 段：「审核子代理被中断了，没有留下结论。我先确认它已经做完的部分和当前工作树的真实状态。」
```

识别信号：子代理回合以中断收束、没有已完成结论，而工作树里留有它已写入的取证产物；主控必须重新派发才能取得结论。

## 触发条件

子代理承担「先取证、后出结论」的长任务，取证产物写进共享工作树，结论只放在它最后一次交付消息里；本例中审核子代理被中断了，且中断发生在完成大部分取证、尚未交出结论时。若中断发生在取证开始之前，或结论已随消息交付，则不触发本形态。材料未记录中断的具体来源。

## 根因

子代理的两类产出走不同通道，造成「产物可复用、结论不可取回」的不对称：写进工作树的取证是持久化的共享状态，子代理进程被中断不会回收它；结论则是子代理回合的最后一条交付消息，中断使该消息不存在。于是主控只能先确认它已经做完的部分和当前工作树的真实状态，再据以决定重派范围。已观察：中断后没有留下结论，且主控确实先核对了已完成部分与工作树状态。未确证：中断的具体来源、已完成取证的比例，以及重派是否完整复用了这些产物。

## 解决

主控的实际处置是先核对遗留产物、再重新派发：确认它已经做完的部分和当前工作树的真实状态，把半成品与已完成改动区分开，然后重新派发审核，把已完成的取证当作新材料复用、不从头重做。成功信号（材料记载）：重新派发并复用其遗留产物使审核得以继续。必要边界：材料只记录到「只能重新派发并复用其遗留产物」，重派的任务书、复用比例与最终结论均未逐字记录，本条不据记忆补写。

## 规避

派生「先取证、后结论」的子代理时，在任务书里要求它把结论也落盘（写到约定文件或工作树中的产物文件），而不是只放在最后一条消息里；取证过程也分段落盘，使中断后能复用的不止原始证据，还有已完成部分的判断。主控遇到审核子代理被中断了的情形，先核对工作树真实状态与产物完整性，再决定重派范围，避免重复取证；若子代理只能交付消息结论，则把「中断即需重派」当作已知成本，把取证与结论拆成两段可分别交付的任务。例外：任务很短、重派成本低于落盘约定时，直接重派。

## 验证

已观察：审核子代理被中断了，没有留下结论；主控随后确认它已经做完的部分和当前工作树的真实状态，并重新派发、复用遗留产物（材料现象段所述）。未覆盖：中断的具体触发与发生位置；已完成取证的实际比例与复用完整性；重派后的审核结论是否一次成功；该形态在非审核类子代理任务上的表现。

## 影响与适用范围

适用于主控派生隔离子代理做取证或审核、子代理在交出结论前被中断（超时、取消或执行体异常等）的场合：其已完成的取证若写在工作树或文件里仍可复用，而结论只存在于最后一次交付消息中，随中断一并丢失；不适用于子代理已把结论落盘、或中断发生在任何取证之前的情形。

展开——何时可能踩到：把长任务交给零上下文隔离子代理、且结论只在交付消息中，子代理又在收尾前被中断时；尤其出现在审核子代理被中断了、而它已完成大部分取证的「先取证、后出结论」链路。经验何时可信：工作树里确实留有该子代理的取证产物、且其回合没有已完成结论时，可据此先复用产物再重派；若子代理已把结论写入文件，或中断发生在取证之前，则不适用本条。
