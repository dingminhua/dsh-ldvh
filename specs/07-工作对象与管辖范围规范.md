## 1. 价值判断

| 价值维度 | 判断要点 |
|---------|----------|
| V1 定位 | 管辖判定引用的登记文件位置固定可回指；工作对象涉及的 Git 根、事实源路径（`ldvh-base/`，由 06 认定为受管载体位置）、规范路径（由 01 定义）均有明确来源 |
| V3 边界识别 | 非管辖项目时 Web 功能隐藏、操作被拒绝；登记文件不存在或损坏时暂停操作并提示 Human 处理 |
| V6 工作接续 | 登记文件保留项目登记状态，新会话可读取登记列表恢复管辖判定结果 |
| HV2 授权受控 | 管辖判定结果作为 Helper 操作与 Git Gate 的机械门禁输入，未登记项目被拒绝受控操作 |

## 4. 管辖登记制度

### 4.1 固定位置
- **Mac**: `~/dsh-ldvh/`
- **Windows**: `%USERPROFILE%\dsh-ldvh\`
- 该文件夹为 LDVH 管辖登记的唯一固定位置

### 4.2 登记载体
- 文件夹内包含一个登记文件（具体文件名/格式本规范不定死，实施时确定；实施确定后须回写本规范或新增授权附件登记）
- 登记文件记录所有 LDVH 管辖项目的列表

### 4.3 判定方式
- 每次判定时，只读该登记文件
- 判断当前项目是否在登记列表中
- **不做向上遍历**（废弃 v4 向上找 `LDVH-GOVERNED-PROJECTS.yaml` 的做法）

### 4.4 登记入口
1. **AI 入口**: 在项目目录内，用户对 AI 说"帮我把当前项目设为 LDVH 管辖" → Helper 先只读登记文件确认当前项目不在列表中，再写入登记文件（写入应使用原子操作防并发竞态，宿主机制支持情况由 08/09 实现时核验）
2. **Web 入口**: 通过 Web 界面（归 10 规范）管理登记列表

### 4.5 前置条件
- **必须**是 Git 项目（存在 `.git` 目录）
- 非 Git 项目不允许登记

### 4.6 自动创建
- 首次登记时，若 `~/dsh-ldvh/` 文件夹不存在，AI **自动创建**该文件夹并写入登记文件
- 管辖配置路径（`~/dsh-ldvh/`）在 Web 界面（归 10）与 AI 登记响应中向用户展示

### 4.7 取消登记
- AI 入口：用户一句话要求取消 → Helper 从登记文件中移除
- Web 入口：通过 Web 界面操作移除


## 5. 工作对象

**前提**: 工作对象成立的前提是项目已登记且为 Git 项目（§4.5）。
- **定义**: 工作对象 = 当前项目 Git 根目录 + 事实源路径（`ldvh-base/`）+ 规范路径（`specs/`）
- **边界**: 工作对象**不跨越多个项目**（单项目单 worktree）
- **未来方向**: 多项目聚合归未来规范（v4 多项目聚合做法废弃）


## 6. 管辖判定消费方

| 消费方 | 消费方式（语义接口，不描述具体 UI/传输细节） |
|--------|-----------------------------------------------|
| Helper | 在执行 LDVH 操作前调用管辖判定，未管辖时拒绝操作 |
| Git Gate | 在 Git Hook 事件中检查管辖状态，未管辖时阻断提交 |
| Skill | 执行前检查当前项目是否在管辖列表 |
| Web | 参照管辖判定结果决定功能呈现与隐藏 |


## 7. 验证与证据边界

| 验证项 | 证据来源 | 边界说明 |
|--------|----------|----------|
| 登记文件存在性 | 文件系统 | 只验证 `~/dsh-ldvh/` 文件夹及登记文件存在 |
| 登记内容有效性 | 登记文件 | 只验证项目路径格式，不验证项目实际存在性；登记文件可定期或在启动时校验项目路径存在性与 `.git` 目录，发现孤立记录时标记为"幽灵登记"并提示 Human |
| Git 项目检查 | `.git` 目录 | 必须存在 `.git` 目录才允许登记 |
| 判定结果一致性 | 登记文件 | 多次判定结果应一致 |
| 消费方行为 | 各消费方日志 | 验证消费方是否按判定结果执行 |


## 8. Human Gate / Stop Conditions

| 条件类型 | 具体条件 | 处理方式 |
|----------|----------|----------|
| 非 Git 项目 | 无 `.git` 目录 | 拒绝登记，提示用户 |
| 登记文件损坏 | 文件格式错误 | 拒绝操作，提示修复 |
| 文件夹创建失败 | 权限问题 | 拒绝登记，提示权限 |
| 项目已登记 | 已在列表中 | 提示已登记，不重复写入；写入使用原子操作，防并发重入 |
| 项目未登记 | 不在列表中 | 拒绝 LDVH 操作 |
| 幽灵登记 | 登记路径存在但项目 `.git` 目录不存在 | 标记为孤立记录，提示 Human 确认是否移除 |


## 9. 反过度设计红线

| 红线项 | 说明 |
|--------|------|
| 不得向上遍历 | 严禁向上查找登记文件（废弃 v4 做法） |
| 不得跨项目操作 | 工作对象严格限定在单个项目内 |
| 不得硬编码路径 | 登记文件名/格式不得在本规范中硬编码 |
| 不得绕过 Git 检查 | 必须验证 `.git` 目录存在 |
