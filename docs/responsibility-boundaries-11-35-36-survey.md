# 11 / 35 / 36 职责边界调研报告

日期：2026-11-18。触发：Human 判断「11 号（代理辅助）是机制、35/36 是两个业务，三者职责混淆」。本文只取证与形成结论，**未改任何规范或代码**。

## 0. 结论先行

1. **职责混淆成立，但根因不是「机制放错了文件」，而是「2026-11-16/17 把经验运行侧从 11 号搬走时，只搬内容、没改指向」。**
2. **真正吞掉经验运行机制的不是 35 号，是 23 号事实类型规范**（23 §13 承载了触发/上下文供给/代理起草/主控写入/失败处置五项机制要素，而 23 的身份与职责均未申报运行机制）。
3. **不建议「把经验机制回收到 11 号」**：职责分配已是根级事实（00 §5.2、术语表、11 自身放弃声明、23 §13 一致），回收等于撤销两项 Human 决定并触 00 §3.2 根决定闸，收益与代价不匹配。
4. 建议方案 **B′**：保留现分配 + 修全部悬空指针 + 在 11 号把跨两侧通用的运行纪律升格为正条 + 给「反思」安排运行承载或如实登记缺口。
5. 「积累经验」开关目前确为摆设；补消费点可照搬发现摩擦开关的做法，但经验侧须落 **三处**（arm_delegate / 分身 create / 根面 create），且第三处须解决「根面 create 同时承载 Human 入口」的歧义——Human 亲自提出不应被「不再自动记录」的开关挡住。

## 3. 更深的问题：机制被 23 号事实类型规范吞掉

23 §13（23:251-272）现行承载了经验运行机制的**全部五项要素**：

- 触发条件（251）：主控在当次行动中发现已查明验证的失败机制；
- 上下文供给（264-269）：零上下文派生、主控交材料、禁继承、逐字引证；
- 代理起草（251）：草稿先落盘、只起草不写事实源；
- 主控写入（251）：受控创建 + 写后精确回读 → `active`；
- 失败处置（263）：00 §4.7 暂停 + §4.8 交还登记。

但 23 的身份块（23:10-11）只自述为 Pitfall **事实类型**唯一权威，§3.1 六项职责（23:39-46）**无一项是运行机制**。「机制被业务规范吞掉」成立，吞它的是 23，不是 35。

另有两处机制真空/悬空：
- **反思**（35 §8.5:315-322，四条触发信号）全库无运行承载——业务声明了机制、机制层无家；
- 03:336、06:279、11:184/619/628、23:109/251/316/341 仍指向已删的 11 §10 或「三通道/机械通道」；11 §18 仍有「经验对象的查重已执行（依据本规范 §10）」行。

## 5. 建议方案 B′（四个动作）

1. **修全部悬空指针**：35:11/67/75/90/117/125/204/214/259/311/352/412；03:336；06:279；23:109/251/316/341；11:184/619/628。统一口径：「经验运行机制见 23 §13，11 号只承接摩擦发现」。
2. **删 23 号的机械通道/三通道残留**：23:251「机械通道——11 §10.2 第 3 项」与「三条通道」标题与 00:295、11:612「经验侧机械通道已不存在」冲突，属**必须删的活条款**，不是改指针。
3. **在 11 号把跨两侧通用纪律升格为正条**：触发锚共性、上下文供给有界性与禁继承、引证须落在交付材料内、fail-closed 的经验侧领域增量——把 11:213 这类「对经验侧有义务却声称不涉经验侧」的旁注（11 §8:243 冲突）升为正条并注明适用两侧，消掉「有义务无管辖」。

36 号基本不动；仅可考虑把 §14/§8 里重复的 N=3 判据改为回指 11 §9（N 的唯一来源），属可选优化。

## 6. 「积累经验」开关：现状、精确落点与边界

**现状**：`experienceAccumulationEnabled` 只在 index.js:178（schema）、client.js:1027/1139/1326/1637（显示/保存）、idle-settings.js:178（解析）出现；经验写入面不看它 → 截图承诺的「关掉后不再自动记录经验」未实现。诊断面 ldvh-tools.js:1345-1349 却已把它报成生效状态。

**落点（三点缺一不可，照搬发现摩擦开关的「传函数 + 副作用前早退 + lifecycle 闭包」）**：
1. `pitfall-tools.js:488` `executeArmDelegate` 早退——关时不记新授权；
2. `pitfall-tools.js:276-310` 分身 create 早退——堵关掉之前已 arm 的分身（授权持久化、TTL 最长 1 小时，只堵 arm 会漏）；
3. `pitfall-tools.js:246/332` 根面 create 早退——AI 按 guidance-text.js:121 被指示走的就是根面自写；但根面同时承载 Human 入口，须用显式发起标记放行 Human，不得把 Human 亲自提出也挡掉（文案是「不再**自动**记录」；挡 Human 入口属 00 §3.2 范围）。
4. lifecycle:363-369 分身 deps 与 :407-410 旁补 `isExperienceAccumulationEnabled` 闭包；根面 deps 已含 getIdleSettings（lifecycle:442）可直接传。
5. child.js 不需要改（经验面不在 child.js 注册）；**不要**在注册时刻按开关决定是否注册（会把后来打开开关冻死）。
6. idle-settings.js 无需改映射（经验行没有摩擦那种读错键的病）；但有陈旧注释（:161-163 仍称 frictionDiscoveryEnabled 是现役键）与旧键 `experienceCaptureEnabled` 无回落的边角问题，顺手处理。
7. 不要堵 `action=update`（Human Gate 的 active→discarded 走 update，堵了等于挡 Human 废止）；诊断 verdict 应区分子项关闭；新增测试并同步 baseline（当前 2411）。

**规范与代码分歧须一并登记**：guidance-text.js:121 说「子代理不写事实源」，代码却允许被授权分身直接写事实源（pitfall-tools.js:276-310）；「开工授权/代理记录通道」在 specs/ 零命中。开关落点依赖这条通道，须同时处理该分歧。
