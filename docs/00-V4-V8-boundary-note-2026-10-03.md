# 00 §6 V4「稳定推进」与 V8「持续积累」的差别（非规范对照说明）

> **性质**：开发备忘。**非规范、非事实对象，不取得规范效力**；规则正文以 `specs/00-理念与构成.md` §6.1 为准。
> **缘起**：2026-10-03 会话中 Human 提出「稳定推进与持续积累似乎一样，能否把 V4 去掉」。本文件回答该问题，不改动任何规范。

## 一、原文（工作树当前）

- **V4 稳定推进**：能否帮助 AI 在 LDVH 已明确支持的场景中，复用适用的行动结构、调用可用能力，并及时获得能够支持后续调整或分流的确定性反馈。判据：执行复用既有行动结构并记录复用依据。
- **V8 持续积累**：能否帮助 AI 在后续事项中复用当前工作形成的经验，并继续处理已经发现的反复问题以及规则或能力缺口。判据：相似事项的执行复用既有经验与结论。

## 二、五条差别

| 维度 | V4 | V8 |
|---|---|---|
| 复用的对象 | **行动结构**——干这类活的骨架与流程 | **经验与结论**——做完之后学到的东西 |
| 时间指向 | **当次**：这一次能不能顺利推下去（进行中：有反馈、能调整、能分流） | **跨事项**：下一次遇到相似事项能不能省事 |
| 判据性质 | 结构性证据（当次按既有骨架执行并留痕） | 知识性证据（相似事项真的用上了既有经验与结论） |
| 缺失时的失效形态 | 每次都从零编排、中途卡住/无反馈 | 同一个坑反复踩、同一个问题反复争论、结论反复调研 |
| 对应 §1 的哪个问题 | §1 第 3 项「眼前进展与任务难以接续」（执行侧） | §1 第 4 项「历史经验与教训无法积累」（积累侧） |

**下游规范的分工实证**（说明二者在实践中已被区分对待）：

- `21:31`：V4＝「复用既有工作包结构并保留接续入口」；V8＝「关闭记录与 outcome 是后续同类工作的复用依据」。
- `35:31`／`35:45`：V8 为本系统**主要兑现**（晋升留痕、效用审计），V4 只是**同时支撑**。
- `32:31`：V4＝「attempt 接续与既有工作包结构复用」。
- `03:27`：V4／V6／V8 归入「接续与积累机制」，但该机制组同时承载对象身份、指纹、关系、受控更新、回读与处置——三者共享底座、判据不同。
- `02:26`：分组映射把「记忆、调研与复核」主要支撑 V4–V5、V7——V8 不在其中。

## 三、交集与边界（如实说明重叠）

- **交集**：两条都以「复用」为动作，且都依赖稳定承载；V4 留下的复用依据（记录）会成为 V8 的原料。
- **边界（互不蕴含）**：
  - V4 成立而 V8 不成立：这次照着既有骨架干完了，但没有沉淀出可复用的经验与结论；
  - V8 成立而 V4 不成立：复用了别人留下的结论，但这一次没有可复用的行动结构可依；
  - 因此二者**不能互相替代**，也不能由一条推出另一条。
- **结论**：V4 与 V8 不是同一条；相似感来自共用的「复用」这个动词，而非同一判断对象。

## 四、若仍要删 V4：代价（实测，非推断）

1. `00 §4.2:166` 把「改变 V1–V8 的数量、编号、名称、判断问题或价值边界」列为**只能由 Human 决定**的根决定事项——删 V4 即改变数量与编号。
2. 全库指名引用（**数字已更正**）：按正则 `(?<!H)V4` 精确计数，`V4` 在 `specs/*.md` 为 **14 行、11 份规范**；`V8` 为 **25 行、18 份规范**。`00` 自身另有 §2:79、§4.2:166、§6.1 标题「V1–V8」等编号载体。
   **更正说明（2026-10-03，防自欺纪律）**：本备忘初稿写「V4 38 处／20 份、V8 28 处」，该数字**错误**——正则 `V4` 会把 `HV4`（23 行／14 份）一并匹配。精确口径以本行为准；初稿数字作废，不得引用。
3. 删条后有两条路，代价都不小：
   - **重编号**（V5–V8→V4–V7）：牵动 `00`＋**11 份**引用 V4 的规范的「价值声明／主要支撑」行，以及 `01 §12` 第 1 维「价值判据对齐」的比对基准；
   - **留空号**：`§6.1` 标题「V1–V8」与全库引用随之失真，属更差状态。
4. 收益（少一条标准）与代价（全库重排 + 根决定 + 独立审核 + 受保护内容程序）不相称。**不建议删除。**

## 五、若只是「读起来像」：最小改法

- **最小**：本说明不动规范（现状）。
- **次小**：只改两条的措辞、不改条数——V4 向「当次能否顺着既有骨架推进并留下复用依据」收，V8 向「跨事项能否越做越省」收。注意：改「判断问题」同样落在 `§4.2:166` 的对象面内，**仍属根决定**，须独立审核 + Human 决定 + `§4.3` 程序。
