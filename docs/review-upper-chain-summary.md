## 二、**核心结构性发现**：「元规范/事实规范」两级分工在下位全链缺席

这是本轮**最重要的发现**，由 01 与 03 两条独立路径得出，并经主控机械复核：

```
「元规范」在 specs/ 中的分布：
  00-理念与构成.md          5 次   ← 根规范，定义并使用了它
  27-Norm-事实规范.md      10 次   ← 本轮新建
  27.Att.01-方向清单.md     6 次   ← 本轮新建
  01-规范模型基础规范.md     0 次   ← 应定义归属判断（00 §3.3:136 指派）
  02-工作模型基础规范.md     0 次
  03-事实模型基础规范.md     0 次   ← 应给「事实规范」留位（00 §3.3:132）
  04-业务系统基础规范.md     0 次
```

**00 的指派与实际承接的落差**：

| 00 的要求 | 应承接者 | 实际 |
|---|---|---|
| §3.3:136「具体归属判断**由规范模型定义**」 | 01 | ❌ 01 中「归属判断」0 次；§5 角色清单只列根/普通/附件，**未立 meta/fact 轴** |
| §3.3:132「事实规范承载管辖项目的规则，**以事实对象形态承载于事实源**」 | 03 | ❌ 03 中「事实规范」**0 次**；未给 27（事实规范类型）留位 |
| §3.2:128「事实对象可以承载规范（事实规范）」 | 03 | ❌ 同上 |

**→ 结论：00 建立了「元规范 / 事实规范」两级承载，并在 §3.3 把归属判断指派给规范模型；但该指派在 01 与 03 中均无落地。** 27（事实规范类型）是本轮新建，**它建立在一个两级分工尚未在下位定义的基础上**。
